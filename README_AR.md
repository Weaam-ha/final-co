# مشروع المترجمات: واجهة تفاعلية ثابتة مع إعادة توليد تلقائية

> يوجد **مساران منفصلان** يعملان معاً، ولا يكتب أي منهما فوق الآخر إلا عند حفظ ملف المصدر: الواجهة تسمح بإضافة المنتجات وحذفها واختيارها محلياً، بينما المترجم يعيد توليد الواجهة من الكود عند حفظ ملف Python أو القالب.

## السلوك المطلوب والمطبق

| الإجراء | النتيجة |
|---|---|
| تضيفين أو تحذفين منتجاً من الصفحة المفتوحة | يتغير ما ترينه فوراً داخل المتصفح فقط. لا يتغير `flask_app.txt` ولا أي ملف مصدر. |
| تعدّلين `compiler2/flask_app.txt` ثم تحفظين | تلتقط المراقبة التعديل، تعيد الترجمة، وتستبدل `output/index.html` و`style.css` و`script.js` من المصدر الجديد. |
| تعدّلين `compiler2/front_test.txt` ثم تحفظين | تعيد المراقبة توليد الواجهة من القالب الجديد. |
| تعيدين تحميل المتصفح بعد توليد جديد | تظهر بيانات المصدر الجديدة، وتبدأ تفاعلات الواجهة من المخرجات الجديدة. |

## المكوّنات

| الملف | دوره |
|---|---|
| `compiler2/flask_app.txt` | مصدر بيانات Python الذي يحلله المترجم. هذا هو المكان الصحيح لتعديل بيانات المصدر. |
| `compiler2/front_test.txt` | قالب Jinja وHTML وCSS المصدر. |
| `Main` | ينفذ التوليد الأول ثم يبدأ `WatchService` تلقائياً. |
| `WatchService` | يبقى شغالاً ويراقب `flask_app.txt` و`front_test.txt` فقط. عند الحفظ يستدعي `compileOnce()` داخل نفس عملية Java. |
| `output/index.html` | HTML ثابت مولّد ويستدعي `script.js`. |
| `output/script.js` | إضافة المنتج وحذفه واختياره محلياً داخل المتصفح فقط؛ لا يرسل طلبات Flask ولا يعدّل ملفات المصدر. |
| `output/style.css` | CSS مولّد. |
| `compiler_output/` | ملفات AST والتقرير الدلالي وسجل التوليد المطلوبة للتسليم. |

## التشغيل في IntelliJ

شغّلي `Main` مع **Working directory** مضبوطاً على المجلد `compiler003/` الذي يحوي مجلد `compiler2/`. لا تضيفي أي `Program arguments`.

بعد التوليد الأول، يجب أن يبقى الـConsole مفتوحاً وتظهر رسالة مشابهة:

```text
WATCH SERVICE STARTED
Watching only: flask_app.txt and front_test.txt
Press Ctrl+C to stop.
```

لا ينبغي أن تنتهي العملية وحدها. لإيقافها استخدمي زر Stop في IntelliJ أو `Ctrl+C` فقط.

## كيف تستخدمين المشروع؟

افتحي `output/index.html` في المتصفح. تستطيعين إضافة منتجات أو حذفها أو اختيارها؛ هذه تغييرات محلية تخص الصفحة المفتوحة فقط ولا تغيّر كود Python. عند إعادة فتح الصفحة أو تحديثها، تبدأ الواجهة دائماً من بيانات المصدر المولّدة حديثاً، لذلك لا يمكن لبيانات متصفح قديمة أن تخفي منتجاً من `flask_app.txt`. وفي الوقت نفسه اتركي `Main` شغّالاً.

عندما تريدين تغيير **البيانات المصدرية النهائية**، عدّلي قائمة `products` في `compiler2/flask_app.txt`، ثم اضغطي **Ctrl+S**. ستظهر في الـConsole رسالة عن التغيير وإعادة التوليد. بعد ذلك اعملي Refresh للمتصفح لرؤية HTML الجديد الناتج من الكود.

```text
تعديل المصدر + حفظ
        ↓
WatchService يكتشف التعديل
        ↓
compileOnce()
        ↓
تُكتب مخرجات output/ جديدة
        ↓
Refresh في المتصفح
        ↓
واجهة جديدة مبنية من الكود
```
